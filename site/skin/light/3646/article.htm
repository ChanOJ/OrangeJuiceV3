Alambik Script 4, with its authoring tool, Alambik Editor (ALED) has just been released. This new technology combines a complete set of text-based programming instructions with text-based audiovisual commands (video, audio, 2D, 3D, etc.)

This new technology combines a complete set of text-based programming instructions with text-based audiovisual commands (video, audio, 2D, 3D, etc.).

These two conceptual worlds, once distinct, are united synergistically under Alambik within a simple, uniform programming environment that functions in real-time.

Alambik brings together in a single package everything you’ve dreamed about in multicontent production: stunning audio capabilities, digital imaging, full-motion video, real time treatments such as filters and special effects, event-handling, synchronization, programming, mathematical calculation, security, compression, multi-environment compatibility, data handling, client/server networking… the list goes on and on!

An already-established technology, Alambik Script has been carefully developed over the last ten years. Only recently has it been introduced to the Internet, thanks to the porting of its real-time interpreter to the Windows™ operating system.
Thanks to a FREEWARE distribution of the Alambik Basic Core production pack, project creators can get started right away, at no cost.

See for yourself! Check out Alambik in action at http://www.the-demo.com. This website features nearly 200 original Alambik Script examples, all with full source code access! A right click will unveil a contextual menu with options similar to those in any HTML page ("view source", "save as", etc.).

For a comprehensive introduction to the Alambik technology, please visit http://www.alambik.com.
Alambik Script is fully supported. Complete online documentation, bringing together nearly 3,500 html pages and 1,500 basic Alambik example scripts, is now available at http://www.web-language.com.
