When :

The party starts on friday the 2nd of august 2002 and is over on sunday the 4th of august

Financials :

The entrance-price for the party is set at 20 euro. Because the organizers would like their investment to reach a break-even point nobody can enter for free (sorry girls)

Any money that is left over after all the costs have been payed will go to the competitions as prize-money.

Competition Rules :

Graphics : - Use any C64 resolution that you want as long as it can be displayed on a normal monitor / tv
- Images have to be delivered in a runnable format
Music : - Any runnable file will do
- Maximum playtime is 3 minutes per entry
- Screen output will not be shown
- We will play the tune on whatever machine we want, not caring about old or new SID. If this matters please say so when handing in your tune
Demo : - The demo has to run on a pal C64 with a 1541 diskdrive
- Please try to make it MK Cartridge compatible - it saves yanking it from the cartridge port over and over again
- A maximum of 15 minutes will be shown
- Maximum size is one 5 1/4 disk (both sides)


Entries have to be delivered on a 5 1/4 floppy disk - compo disks will not be returned afterwards.
