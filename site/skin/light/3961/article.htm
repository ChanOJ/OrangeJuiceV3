OK, suppose you met someone who is excited about creating a demo, but is entirely new to the "scene". Assume that the person is already talented at visual arts, music, or coding. You want to give them a CD-R that has some demos, some tools and some advice. The included demos are ones you've chosen from the various archives to inspire the new scener and also to give them an idea of what the current 'state of the art' is that they'll have to match or exceed if they want to be considered one of the best. The tools are in the form of software, so that they can use the CD to get their feet wet right away without having to hunt and search all over the archives on the net for them. The advice is in the form of some interlinked HTML files that you've created, giving them basic outlines for things to do in creating a demo, like starting with a storyboard, blocking out the sequences, thinking of effects that enhance each sequence, planning out the music tracks, etc. The HTML files would also include links to places like ojuice.net, scene.org, etc. So that's the idea, the question I have for you sceners out there is what tools would you include? As a coder, I'm familiar with the kinds of tools you need to develop code, but there's more to a demo than code, there is "content": music, text, still images, 3D models, and so-on. So what tools would you include for: - music composition - still image creation - 3D modelling Keep in mind that I'm no software pirate, so the tools must be freeware, shareware, or trialware that can be legally dist'ed on a CD-R. Also, text is easy to compose in any editor, but perhaps there are some structural/thesaurus/permutation tools out there that operate on text to produce interesting results? That could be fun too. If you have other specific suggestions you think should be included on such a CD-R, I'd like to hear about that too. legalize@????
