  DevLib 1.5.1 released ! ..218 clicks..
DevLib 1.5.1 has been released at DevLib Central. It is designed to make multimedia production (games, screen-savers, demos..) easier and more intuitive to write. Still compatible with DevCpp and VC7, using OpenGL and DirectX abstraction, this version introduces MacOS X support, a robust documentation covering the whole API (78 pages!), many new samples, enhancements and bugfixes.
