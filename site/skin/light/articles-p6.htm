Guide To Exploring File Formats ..261 clicks..
After repeated requests from sceners and non-sceners Mr.Mouse/XeNTaX and Watto/Watto Studios, authors of MultiEx Commander and Game Extractor respectively, teamed up to write The Definitive Guide To Exploring File Formats (DGEFF). DGEFF is a 65 page tutorial that explains how to uncover archive structures, strategies to crack unknown file encryption and compression and much more, from the basics to the more advanced methods. DGEFF is available as an Adobe PDF file. Click above to go the XeNTaX website and retrieve it.
Mr.Mouse / XeNTaX
