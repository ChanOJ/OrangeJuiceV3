Invitation:
-------------------------------------

Syndeecate Apocalypse 2002 is like Syndeecate 2001 party. The difference is
in number of platforms. Last year, there was only one - i386. This year,
four platforms are planned and supported: Amiga (every model
CISC-68k/RISC-604e), ZX Spectrum 128, PowerMAC (Apple), i386. You can compete
on any platform.

Maybe you know Apocalypse party, which was held for three years in Brandys
nad Labem by Lahve^Reason/Scoopex. Because we want more people, more fun,
more contributions we are joinin Syndeecate and Apocalypse in one BIG
party.

Where : Country - Czech Republic, Town - Roznov pod Radhostem, Exact place
(bulding) will be annonced in a 2 weeks, check www.syndeecate.cz
When : 16.-18.8.2002
Entrance fee : 200Kç (=6EUR)

For more informations please visit : http://www.syndeecate.cz

Rules:
-----

ZX Spectrum:
+++++++++++


There will be 2 computers on the party place so you can choose
which one will be used for your production.

a) Didaktik Gama 128 with D80 disk drive, TAPE, AY3-8912 in ACB
stereo, RS232 and 3 channels 8Bit D/A.
This is Slovak clone of Sinclair ZX Spectrum 128 - black.

b) Sinclair ZX Spectrum +2A with external +3 Interface, 3,5" and
5,25" DD disk drive. AY is in ACB stereo.

Music compo:

you can make both BEEP music and AY music. No matter WHICH Tracker
you will use. But if you use something special, PLAY routine MUST
BE included. Please write short read.me HOW to play your special
tune. Thanks to 3 channels 8Bit D/A you can use 8Bit samples in
Sample Tracker (Luxus Software). There is only two limitations:

- two tunes per musician
- 4 minutes per song

Graphics compo:

you can use classic 256x192 picture or Multicolor scr., interlace 256x384 or
multichrome picture. For Interlace, Multicolor and Multichrome
player routine MUST be included.

- two pictures per graphician

Demo compo:

there is only system "limitations"

- special TAPE loaders are prohibited
- you must use Basic and LOAD "" command
- machine code must be loaded from 25000 and upper address
- you can't use command OUT 32765,XX for paging in Basic;
everething must be done in machine code.
- +3 system friendly = 17th and 23rd page must be
loaded&decrunched at last, after this, ei instruction with
basic's calls is very dangerous for +3 system. To be absolutely
sure, delete +3 paging routines at 23296.
- when you are not familiar with +3 or there is no chance to try
your production under +3 don't worry; we will run your demo on
DG128 or I will try to +3 fix it :)

Intro compo:

- only length limitations : 512B, 1024B or 4096B.



Amiga:

we will have four Amiga machines on the party place, so you can
choose the type you and your contribution are familiar with ;-)

Amiga 500+ :

Amiga 500 with 1,5MB of CHIP RAM, 8MB FastRAM, ECS chipset,
MacroSystem SCSI-2 Controller and 2GB Seagate drive.
OS : AmigaOS 2.1, KickStart 2.05

Amiga 1200 :

Amiga 1200 with DCE Blizzard 68060/50MHz, 2MB CHIP RAM, 32MB of
FastRAM, 4,8GB IBM IDE HDD, AGA chipset and Micronic ScanDoubler.
OS : AmigaOS 3.9, KickStart 3.1

Amiga 4000:

Amiga 4000 with 2MB CHIP RAM, 16MB onboard FastRAM, 96MB of
FastRAM on CyberStormPPC, UltraWide SCSI-3 controller and
Seagate 4,5GBdrive, CD ROM and 1GB Seagate IDE drive. Dual CPU
system 68040/40MHz and 604e/180MHz. CyberVisionPPC gfx card with
8MB RAM. We hope PCI Bridge will come soon, so we are expecting
VooDoo 3 - 3000 GFX board, Ethernet and 16Bit Sound.
OS : AmigaOS 3.9, KickStart 3.1

Amiga 4000:

Amiga 4000 with 2MB CHIP RAM, 4MB onboard FastRAM and 96MB
FastRAM on CyberStorm MK II card with 68060/50(56)MHz CPU,
CyberVision64 gfx card, SCSI-2 controller and 2GB SCSI disk, SCSI CD ROM.
OS : AmigaOS 3.9, KickStart 3.1


Music compo:


Samples : 8Bit or 16Bit samples
Trackers : OctaMED 3,4,5,1.03, DigiBooster, AHX,
MusicLine, ProTracker 4 or what you like :)

limitations:

- one song per musician
- only 3 minutes of song will be played

in read.me file must be these fields:

Author, Handle (nick), Name of Song, Tracker and recommended player
and AHI System parameters! /is it possible we will have 16Bit
SoundCard instead of 8Bit 4Channels DMA Paula chip/


Graphics compo has 2 categories:

- "pixel" screen
- raytraced screeen

2 pictures per graphician, no other limitations in resolution. In
read.me file please write: Author, Nick, Name of the picture,
Used draw programme/raytracer etc., recommended viewer and
recommended chipset (ECS/AGA/CyberGraphX and its GFX cards)


Demo compo:

- everything needed by your programme must be included in the
archive (lha or lzx)
- don't use an asssigns, everything I need to run the programme
is to type xxxxxx.exe.
- there is only limitations to our compo machines :) So choose
one and write read.me file how to run it and others important
things.
- system friendly demos are strongly recommended! (e.g.
executable from WorkBench)
