  MO3 format is becoming unofficially open ..196 clicks..
I'm currently writing the unofficial specification and some source code for the MO3 format (the format at www.un4seen.com). So now this format can be considered open, and can be used to write a DUMB loader for example (dump.sf.net), parse the patterns data, extract samples... whatever. The hard thing was to understand packing algorithms and write a C version. Unpacking source code is available today. Complete code in February. For coders/developers.
