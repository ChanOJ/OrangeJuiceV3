You can use several options to make your search more accurate in the people database of Orange Juice.
By default the search is done on the nickname and group(s) of the persons. You can do the search on the other fields by adding "<option>:" before the word you're looking for.

Existing options :

ctry : 2 letters iso code attended
nick : searchs the nickname field
name : searchs the lastname and firstname fields
zip : searchs the zip (postal code) field
reg : searchs the region/department field

Add some * to extend the search

Examples :

ctry:be looks for all the belgian people
nick:cha* looks for the people whose nick begins with cha
The search is done only on the groups links database and it searchs for the exact sentence as you entered it.
