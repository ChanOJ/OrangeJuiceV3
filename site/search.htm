The syntax for the search is almost the same as Altavista.

assembly java : searchs the paths containing either assembly or java

+assembly +java : searchs the paths containing assembly and java

+assembly -java : searchs the paths containing assembly and not java

(there's no space after the "+" or "-" chars)

NB: this search may be very slow.
kasp and ("the party" or theparty or tp) : searchs the files containing kasp and either the party or theparty or tp in their name or path

NB: this search may be very slow.
glop.zip : find a file exactly named glop.zip
(this is the fastest search)
